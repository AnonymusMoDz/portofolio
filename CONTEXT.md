# Luigi Chelini Portfolio

A public website presenting Luigi Chelini's work history, skills and contact details to recruiters and collaborators.

## Language

**Selected Work**:
A short description of work from Luigi's employment history, naming the employer and tech used, with no link or screenshot required.
_Avoid_: Project, portfolio item

**Project**:
A piece of work with a real case study and its own detail page.
_Avoid_: Selected Work, app

**Experience**:
A dated role in Luigi's work history. Experience entries are the evidence for the years claimed on the site.
_Avoid_: Job, position

**Hidden Section**:
A section whose collection is empty, so visitors see no section, nav link or listing page.
_Avoid_: Disabled, coming soon

**Launch**:
The first production deployment, which requires Experience supporting the "8+ years" claim. Preview deployments are not Launch.
_Avoid_: Go-live, release

**Studio**:
The login-protected editing dashboard where Luigi manages all content, including the profile photo.
_Avoid_: Admin, CMS page
